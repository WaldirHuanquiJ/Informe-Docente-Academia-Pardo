# Informe Docente Academia Pardo

Sistema de escritorio para gestionar horarios docentes, asistencia biometrica, calendario laboral, suspensiones e informes PDF con metricas de cumplimiento y deuda horaria.

## Caracteristicas

- Importacion de horarios docentes.
- Importacion de registros biometricos.
- Calendario laboral con dias no laborables y suspensiones.
- Dashboard de metricas docentes.
- Reporte detallado por docente, dia y horario.
- Resumen visual con distribucion de asistencia y deuda.
- Exportacion de informes PDF.
